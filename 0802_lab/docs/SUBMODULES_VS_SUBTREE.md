# Submodules vs Subtree

| Критерий | Submodules | Subtree |
|---|---|---|
| Связь с внешним репозиторием | Сохраняется (ссылка на коммит + `.gitmodules`) | История вливается, связь не обязательна |
| Клонирование | Требует `--recurse-submodules` | Обычное клонирование |
| Сложность | Выше (нужно обновлять ссылку) | Ниже для потребителей |
| Вклад upstream | Удобно (коммиты идут в свой репозиторий) | Сложнее (нужен split) |

Вывод: submodules — когда зависимость живёт своей жизнью (общая библиотека); subtree — когда нужен один репозиторий без внешних связей.
